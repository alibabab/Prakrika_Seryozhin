# Ошибки и их причины

Ошибок, которые помешали работе, не было.

Что встретилось
Команда docker --version до установки написала docker: command not found. Причина: Docker не был установлен. Я установил Docker по официальной инструкции.
Команда sudo systemctl status docker до установки написала Unit docker.service could not be found. Причина та же. После установки служба стала active running.
Во время apt install были предупреждения про нестабильный командный интерфейс apt. Это не ошибка.
Во время установки debconf написал, что нет терминала. Установка завершилась без ошибок.
Ошибок permission denied, port is already allocated и Cannot connect to the Docker daemon не было.
Контейнер up04-web был остановлен и удалён после проверки. Массовую очистку я не делал.

Вывод
Все команды из задания выполнились. Серьёзных ошибок нет.
