# Работа с контейнерами

Первый контейнер hello-world
Команда sudo docker run hello-world скачала образ hello-world:latest и написала Hello from Docker! и короткую инструкцию.
Команда sudo docker images показала образ hello-world:latest.
Команда sudo docker ps показала пустой список.
Команда sudo docker ps -a показала контейнер hello-world со статусом Exited 0.

Веб-сервер nginx
Команда sudo docker run -d --name up04-web -p 127.0.0.1:8080:80 nginx:alpine скачала образ nginx:alpine и вернула длинный номер контейнера.
Команда sudo docker ps показала контейнер up04-web со статусом Up и портом 127.0.0.1:8080.
Команда curl -I http://127.0.0.1:8080 вернула HTTP/1.1 200 OK и имя сервера nginx.
Команда sudo docker logs up04-web показала запуск nginx и запрос HEAD / HTTP/1.1 200.
Команда sudo docker stats --no-stream показала 0 процентов CPU и около 2.7 МиБ памяти.
Команда sudo docker stop up04-web перевела контейнер в статус Exited.
Команда sudo docker start up04-web снова запустила контейнер.
Команда curl после запуска снова вернула HTTP/1.1 200 OK.
Команда sudo docker inspect показала Name /up04-web, State running, Image nginx:alpine и порт 8080.
В конце я остановил и удалил контейнер up04-web. Образ nginx:alpine оставил.

Ответы на вопросы
1 Образ — это шаблон с файлами приложения. Контейнер — это запущенный экземпляр образа.
2 hello-world выполнил свою команду и завершился. nginx работает постоянно, потому что это сервер и он ждёт запросы.
3 Ключ -d запускает контейнер в фоне и возвращает управление терминалу.
4 Ключ --name up04-web задаёт контейнеру понятное имя up04-web.
5 Порт 8080:80 связывает порт 8080 на Ubuntu с портом 80 внутри контейнера. Так nginx доступен снаружи.
6 Адрес 127.0.0.1 разрешает доступ только с самой машины Ubuntu. Это безопаснее, чем открывать порт всем.
7 Логи видны командой sudo docker logs up04-web. Можно добавить --tail 10, чтобы увидеть последние строки.
8 stop останавливает контейнер, но не удаляет его. rm удаляет остановленный контейнер.
