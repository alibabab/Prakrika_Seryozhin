# Проверка GPU

Команда lspci и результат
Команда lspci | grep -Ei vga показала устройство VMware SVGA II Adapter. Это виртуальный графический адаптер.
Пакет pciutils уже был установлен.

Команда nvidia-smi и результат
Команда nvidia-smi написала command not found. Драйвер NVIDIA не установлен.

Доступен ли вычислительный GPU: нет
Требуется ли GPU моему агенту: нет
Обоснование: агент работает через внешний сервис GigaChat. Модель находится не в виртуальной машине. Для запросов нужен интернет и ключ, а не видеокарта.
